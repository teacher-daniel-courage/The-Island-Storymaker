Choose-your-path games

Every choice leads somewhere

Each scene is a GIF, a bit of story and up to four choices. Players pick one and find out where it goes: another scene, an early death, or the way off the island.

How it works

  1. 1

    Write it

    In the Storymaker, add scenes and connect each option to the scene it leads to.

  2. 2

    Export it

    File → Export story file saves the whole story as one .story.json file.

  3. 3

    Play it

    Open that file in Play a story, or send it to someone so they can play it too.
